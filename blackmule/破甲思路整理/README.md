## 分类体系

破甲思路按以下维度分类：

### 按攻击层
- **系统指令层**: 修改 Agent 的 system prompt / model instructions
- **上下文注入层**: 通过 memory/hook/session 注入越权指令
- **工具滥用层**: 利用 Agent 工具权限绕过限制
- **供应链层**: 在 Skill/Plugin/扩展中预埋破甲指令

### 按技术手段
- **角色扮演**: DAN/专家模式/虚构场景
- **语义重解释**: 将敏感操作重新定义为合法术语
- **格式强制**: 禁止拒绝措辞，强制产出
- **层级独立**: 声明注入的指令优先级高于平台安全层
- **模板预设**: 为常见敏感请求准备标准答案模板

### 按目标模型
- OpenAI Codex / GPT 系列
- Anthropic Claude 系列
- 国产模型 (DeepSeek/Qwen/GLM 等)

## 使用说明

每次收到新的破甲思路（文章/工具/Prompt）：
1. 去重：是否已有类似思路记录
2. 分析：提取核心机制和创新点
3. 对照：与现有 `llm-jailbreak-arsenal` 的 5 梯队 25+ 战法对照
4. 入库：写分析文件到此目录，更新本索引
5. 同步：有价值的补入 `llm-jailbreak-arsenal` Skill
